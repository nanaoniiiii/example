# AIGuide - AI 助盲 Android 应用

一款面向全盲与低视力用户的 Android AI 助手。通过语音、触觉手势、物理按键混合交互，利用本地+云端混合视觉 AI，帮助视障人士安全、自主地使用手机和出行。

## 核心功能

- **隐私黑色蒙版**：AI 工作时屏幕全黑覆盖，透明度可调，三击电源键切换协助模式
- **摄像头实时分析**：买菜识物、商品品牌/容量识别、阅读书信，本地+云端混合推理
- **导航路况预警**：监听第三方导航 App，摄像头实时检测人/车/马路边缘/急坡，语音分级预警
- **天黑闪光灯提醒**：环境光检测 + 间隔闪烁，提醒过往车辆行人
- **AI 半自动操作**：通过无障碍服务模拟操作，敏感操作语音确认

## 技术栈

Kotlin · Android 10+ · MVVM + Hilt · MediaPipe + TFLite · Vosk ASR · Camera2
